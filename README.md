# 🧾 PDF Receipt Generator

**CLI-инструмент для генерации кассовых чеков из HTML-шаблонов и данных CSV/JSON.**

Создаёт printable PDF-файлы кассовых чеков по требованиям ФНС РФ (2026), заполняя HTML-шаблоны данными из файлов. Поддержка кириллицы, редактирование чека перед печатью, автоматическое открытие PDF. **Автоматическая проверка и установка зависимостей при каждом запуске.**

## 🔧 Технические характеристики

- **Язык**: Python 3.9+
- **Генерация PDF**: WeasyPrint 60+ (основной) / fpdf2 (fallback)
- **Парсинг CSV**: встроенная библиотека `csv` + поддержка `utf-8-sig` (BOM)
- **Парсинг JSON**: встроенная библиотека `json`
- **Шрифты**: DejaVu Sans (WeasyPrint) / Arial (fpdf2 fallback)
- **Совместимость**: Windows, macOS, Linux
- **Стандарт чека**: ФНС РФ 2026 (ФЗ-54, ФЗ-101)

## ⚙️ Автоматическая установка зависимостей

При каждом запуске `generate_receipt.py` выполняет **автоматическую проверку окружения** (`check_env.py`):

### Что проверяется:

| Компонент | Назначение |
|-----------|------------|
| **pandas** | Чтение и обработка CSV/JSON файлов с данными чеков |
| **weasyprint** | Генерация PDF из HTML-шаблонов (основной рендер) |
| **fpdf2** | Альтернативный генератор PDF (fallback, если WeasyPrint не работает) |
| **GTK3 Runtime** | Графическая библиотека GTK3 — основа рендеринга WeasyPrint |
| **Cairo** | Векторная графика — используется WeasyPrint для рисования PDF |
| **Pango** | Рендеринг текста — поддержка кириллицы и сложных шрифтов |
| **GLib** | Базовая библиотека — основа GTK3 и gobject |
| **HarfBuzz** | Разметка текста — корректное отображение символов |
| **Freetype** | Рендеринг шрифтов — поддержка кириллицы в PDF |

### Как это работает:

1. Скрипт запускается → автоматически проверяет все зависимости
2. Если что-то отсутствует → показывает список с описанием каждого компонента
3. Запрашивает разрешение на установку
4. После одобрения — устанавливает Python-пакеты через pip
5. Для GTK3 Runtime выдаёт пошаговую инструкцию (технические библиотеки безопасны)

> **Важно**: GTK3 Runtime, Cairo, Pango, GLib, HarfBuzz и Freetype — это **технические библиотеки**. Они не несут вреда компьютеру, нужны только для корректной генерации PDF через WeasyPrint.

### Установка GTK3 Runtime на Windows (для WeasyPrint):

**Вариант A — через Chocolatey (рекомендуется):**
```bash
choco install gtk3
```

**Вариант B — вручную:**
1. Скачайте GTK3 Runtime: [GTK for Windows Runtime Environment](https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Archive/releases)
2. Распакуйте в папку проекта (например `gtk-runtime/`)
3. При следующем запуске скрипт автоматически найдёт библиотеки

### Если что-то не установлено:

Программа **не заблокируется** — будет использован `fpdf2` как fallback. PDF будет сгенерирован, но без поддержки кириллицы в некоторых случаях.

## 🚀 Быстрый старт (для чайников)

Следуйте этим шагам **по порядку**, копируя команды из терминала:

### Шаг 1. Откройте терминал в папке проекта

```bash
# Windows PowerShell:
cd "c:\Users\user\[Папка, где вы разместите проект]"
```

### Шаг 2. Создайте виртуальное окружение

```bash
python -m venv venv
```

### Шаг 3. Активируйте виртуальное окружение

```bash
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# macOS / Linux:
source venv/bin/activate
```

> После активации в начале строки появится `(venv)`.

### Шаг 4. Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 5. Запустите скрипт

```bash
python generate_receipt.py
```

### Шаг 6. Следуйте инструкциям в консоли

Скрипт по шагам спросит:
1. Какой файл данных выбрать (CSV или JSON)
2. Какой HTML-шаблон использовать
3. Какой invoice ID выбрать для печати

### Шаг 7. Отредактируйте чек (опционально)

После выбора invoice:
- Нажмите **1** — откроется Notepad (Windows) или TextEdit (macOS) для редактирования
- Внесите правки, сохраните, закройте
- Нажмите **2** — сгенерируется PDF
- Нажмите **3** — выход

### Шаг 8. Получите PDF

PDF будет сохранён в папке `/output` и автоматически откроется.

## 📊 Формат данных

### CSV (файл: `data/receipts_data.csv`)

Первая строка — заголовки. Каждая следующая строка — один товар. Один чек может состоять из нескольких строк (с одинаковым `invoice_id`).

| Поле | Описание | Пример |
|------|----------|--------|
| `invoice_id` | Уникальный номер чека | `INV-001` |
| `seller_name` | Название продавца | `ООО «Ромашка»` |
| `seller_inn` | ИНН продавца | `7701234567` |
| `seller_address` | Адрес продавца | `г. Москва, ул. Ленина, д. 10` |
| `invoice_date` | Дата чека | `03.08.2026` |
| `invoice_time` | Время чека | `14:32` |
| `cashier_name` | ФИО кассира | `Иванова А.Б.` |
| `shift_number` | Номер смены | `42` |
| `fiscal_number` | Номер ФН | `1234567890123456` |
| `fiscal_sign` | Знак ФП | `345` |
| `payment_method` | Способ оплаты + доля | `Безналичный 100%` |
| `vat_rate` | Ставка НДС | `20%` |
| `product` | Название товара | `Кофе «Бодрость» 500мл` |
| `price` | Цена единицы | `350.00` |
| `qty` | Количество | `2` |
| `Total amount ex.VAT` | Сумма без НДС | `700.00` |
| `VAT` | Сумма НДС | `116.67` |
| `Total amount including VAT` | Итого с НДС | `816.67` |
| `total` | Итого | `816.67` |
| `total_vat` | НДС итого | `116.67` |
| `total_pay` | К оплате | `816.67` |
| `qr_code_data` | Данные QR-кода | `QR:INV-001-2026` |
| `registration_date` | Дата регистрации | `03.08.2026 14:32` |
| `site_url` | Сайт продавца | `www.romashka-shop.ru` |

## 🎨 HTML-шаблоны и placeholders

Шаблон — обычный HTML-файл. Placeholders заменяются данными из CSV/JSON.

### Обязательные placeholders (минимум):

| Placeholder | Описание |
|-------------|----------|
| `{{ product }}` | Название товара |
| `{{ price }}` | Цена |
| `{{ qty }}` | Количество |
| `{{ Total amount ex.VAT }}` | Сумма без НДС |
| `{{ VAT }}` | НДС |
| `{{ Total amount including VAT }}` | Итого с НДС |

### Дополнительные placeholders:

| Placeholder | Описание |
|-------------|----------|
| `{{ seller_name }}` | Название продавца |
| `{{ seller_inn }}` | ИНН продавца |
| `{{ seller_address }}` | Адрес продавца |
| `{{ invoice_id }}` | Номер чека |
| `{{ invoice_date }}` | Дата чека |
| `{{ invoice_time }}` | Время чека |
| `{{ cashier_name }}` | Кассир |
| `{{ shift_number }}` | Номер смены |
| `{{ fiscal_number }}` | Номер ФН |
| `{{ fiscal_sign }}` | Знак ФП |
| `{{ payment_method }}` | Способ оплаты |
| `{{ vat_rate }}` | Ставка НДС |
| `{{ cash_percent }}` | Доля наличных (%) |
| `{{ noncash_percent }}` | Доля безналичных (%) |
| `{{ total }}` | Итого |
| `{{ total_vat }}` | НДС итого |
| `{{ total_pay }}` | К оплате |
| `{{ qr_code_data }}` | Данные QR-кода |
| `{{ registration_date }}` | Дата регистрации |
| `{{ site_url }}` | Сайт продавца |

> **Совет**: используйте тестовый шаблон `templates/receipt_template.html` как основу.

## 🐛 Возможные ошибки и решения

### 1. `ModuleNotFoundError: No module named 'weasyprint'`

```bash
pip install weasyprint
```

> **Или** запустите `python generate_receipt.py` — при первом запуске скрипт автоматически обнаружит отсутствующие пакеты и предложит их установить.

### 2. `WeasyPrintDeprecationWarning` или проблемы со шрифтами

Убедитесь, что шрифт DejaVu Sans установлен:
- **Windows**: обычно comes with weasyprint
- **Linux**: `sudo apt-get install fonts-dejavu`
- **macOS**: `brew install --cask font-dejavu`

### 3. `Error: invalid argument, mkdir`

Проверьте, что у вас есть права на запись в папку проекта.

### 4. PDF не открывается

PDF всё равно сохранён в `output/`. Откройте его вручную.

### 5. Кириллица не отображается

Убедитесь, что:
- Шрифт DejaVu Sans установлен (для WeasyPrint)
- Arial/Times установлен (для fpdf2 fallback)
- CSV/JSON файлы в кодировке UTF-8
- HTML-файл содержит `<meta charset="UTF-8">`

### 6. `AccessControlError` при импорте

```bash
pip install Pydyf>=0.7.0
```

### 7. GTK библиотеки недоступны (Windows)

Автоматически используется fpdf2 как fallback. Это нормально — PDF будет сгенерирован корректно.

Для полноценной поддержки WeasyPrint установите GTK3 Runtime:
- **Chocolatey**: `choco install gtk3`
- **Вручную**: [GTK for Windows Runtime Environment](https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Archive/releases)

### 8. При запуске выводится предупреждение о недостающих зависимостях

Это **нормальное поведение**. Скрипт проверил окружение и нашёл отсутствующие компоненты:
- Python-пакеты: введите `y` для автоматической установки через pip
- GTK3 Runtime: следуйте инструкции для ручной установки

> **Важно**: GTK3 Runtime, Cairo, Pango, GLib, HarfBuzz и Freetype — это **технические библиотеки**. Они безопасны, не несут вреда компьютеру и нужны только для корректной генерации PDF через WeasyPrint.
