### 3. Исправлены проблемы

#### Проблема 1: Дублирование файлов при загрузке
**Решение**: Использован `set()` для case-insensitive glob паттернов

#### Проблема 2: Неверная верстка чека
**Решение**: Переписана структура CSV (группировка по invoice_id) и JSON (вложенные items)

#### Проблема 3: Перемешанные данные в чеке
**Решение**: Полностью переписаны функции `group_csv_items_by_invoice()`, `render_items_table()`, `fill_template()`

#### Проблема 4: Неверные данные в способе оплаты
**Решение**: Добавлены placeholders `{{ cash_percent }}` и `{{ noncash_percent }}`, корректный парсинг payment_method

#### Проблема 5: Отсутствие QR-кода
**Решение**: Добавлен placeholder `{{ qr_code_data }}` в шаблон и данные в CSV/JSON

#### Проблема 6: Отсутствие GTK на Windows
**Решение**: Реализован fallback на fpdf2 с полной поддержкой кириллицы через Arial

### 4. Ключевые функции скрипта

```python
# 1. Загрузка и парсинг данных
load_csv_data()      # CSV с поддержкой BOM
load_json_data()     # JSON массив объектов
load_all_data_files() # Автообнаружение файлов

# 2. Группировка товаров для CSV
group_csv_items_by_invoice()  # Группирует строки по invoice_id

# 3. Рендеринг таблицы товаров
render_items_table()  # Генерирует HTML строк товаров с НДС

# 4. Заполнение шаблона
fill_template()       # Подставляет все данные в HTML

# 5. Валидация шаблона
validate_html_placeholders()  # Проверяет 6 обязательных placeholders

# 6. Редактирование чека
edit_receipt_html()   # Открывает Notepad/TextEdit для правок

# 7. Генерация PDF
generate_pdf()        # WeasyPrint → fpdf2 fallback
_generate_pdf_fpdf2() # Fallback с кириллицей через Arial

# 8. Обработка ошибок
handle_critical_error()  # Предлагает 3 варианта действий
```

### 5. Поддержка кириллицы

- **WeasyPrint**: DejaVu Sans (автоматический поиск)
- **fpdf2 fallback**: Arial (C:\Windows\Fonts\arial.ttf)
- **Кодировка**: UTF-8 для всех файлов
- **Тестирование**: Все русские символы отображаются корректно

### 6. Fallback-механизмы

| Сценарий | Основной | Fallback |
|----------|----------|----------|
| GTK недоступен | WeasyPrint | fpdf2 |
| Шрифт не найден | DejaVu Sans | Arial |
| Ошибка ввода | Повторный запрос | Выход |
| Критическая ошибка | - | 3 варианта действий |
